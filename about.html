⚛️ What You'll Learn

React concepts in action

Cardify isn't just a tool — it's a living, working demonstration of five core React concepts.

01

Controlled Forms

Every input is a controlled component — its value is driven by React state, not the DOM. This is the correct React pattern for forms.

value={form.firstName} onChange={e => update(e.target.value)}
02

State Management

A single state object at the App level holds all form data. useState keeps it immutable — every update creates a fresh copy.

const [form, setForm] = useState({ firstName: "", lastName: ""... })
03

Props

Data flows downward from App → IDCard → InfoRow. Each component receives only what it needs — the "props" contract is explicit and clear.

<IDCard data={form} photo={photo} /> <InfoRow label="ID" value={id} />
04

Reusable Components

FormField renders both inputs and selects. InfoRow handles every card data row. One component, many uses — that's the React way.

// Used 9 times across the form <FormField label="Name" type="text" value={v} onChange={fn} />
05

Dynamic Rendering

The ID card re-renders on every keystroke. Placeholder text swaps for real values. The barcode recomputes. All driven by state.

{fullName || "Full Name"} {validStr || "MM / YYYY"}
06

useCallback & useRef

useCallback memoises the update factory. useRef powers the 3D tilt effect on the card — direct DOM access without re-renders.

const update = useCallback( field => value => setForm(...), [])

📅 Journey

How Cardify came to be

January 2024
The idea sparks
A student needed a quick mock ID for a presentation. No good free tools existed. The idea for Cardify was born.
March 2024
First prototype
First version built as a single HTML file with React via CDN. Basic form + card preview. Shared in a CS Discord — went viral in the community.
June 2024
Multi-page site
Expanded to a proper 4-page website with 3D effects, particle animations, and a polished design system.
2026 · Now
50,000+ cards generated
Used by students across 200+ colleges worldwide. Featured in multiple React learning courses as a reference project.
